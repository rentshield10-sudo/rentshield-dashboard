6. Current lib/quo.ts Requirements

Important fix made/needed: Quo/OpenPhone conversations return participants like:

8622851232

but /v1/messages requires E.164:

+18622851232

So lib/quo.ts must normalize participants before appending them to the query.

Required helper:

function normalizeParticipantPhone(phone: string) {
  const trimmed = String(phone || "").trim();

  if (trimmed.startsWith("+")) {
    return trimmed;
  }

  const digits = trimmed.replace(/\D/g, "");

  if (digits.length === 10) {
    return `+1${digits}`;
  }

  if (digits.length === 11 && digits.startsWith("1")) {
    return `+${digits}`;
  }

  return trimmed;
}

And in listQuoMessages:

for (const participant of params.participants) {
  const normalizedParticipant = normalizeParticipantPhone(participant);

  if (normalizedParticipant) {
    query.append("participants", normalizedParticipant);
  }
}

Quo message directions observed:

outgoing
received

So direction helpers must treat:

outgoing = outbound
received = inbound
